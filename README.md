# 对拍

中文名：**对拍** · 前缀 `duet` · 端口 **7800**

## 骨架（新骨，不是闸对/缝包换皮）

**左轨装载 → 右轨装载 → 同键对齐落差 → 单边悬账 → 对拍结论**

| 对比 | 闸对 | 缝包（已弃） | **对本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→在途→成物 | 单流入→在途→成物 | **双轨独立装载→键对齐** |
| 在途态 | 开腿账 | 拼缝账 | **无开腿/拼缝；悬账是对齐后单边** |
| 产物 | 行程账 | 整件账 | **对齐差 + 对拍结论** |
| 旁路名 | 旁路匣 | 旁路匣 | **悬账单（命名与语义都不同）** |

皮：支付渠道回执 vs 核心记账。去皮：**双源键对齐管道**。禁止做成收银 CRUD、报表看板、工单系统。

## 双轨时钟漂移（已落，非空桩）

裁窗只认**事件时**；**处理时**只决定落处。默认口径「不裁」，双轨对齐 happy path 不变。

| 口径 | 事件时入窗 | 事件时出窗·处理时入窗 | 两时均出窗 |
| --- | --- | --- | --- |
| 不裁（默认） | 已入轨，可对齐 | 已入轨（不裁） | 已入轨（不裁） |
| 事件时严格 | 可对齐（处理时出窗记「迟到」） | **旁路账册**，不进对齐差 | 窗外，不落账 |
| 处理时缓冲 | 可对齐 | **缓冲包待批末**，批末按事件时重裁 | 窗外，不落账 |

- **不静默顶替**：事件时缺失或非法一律驳回，绝不拿处理时冒充事件时。
- **两册互斥**：旁路账册与缓冲包都以 `(轨别, 事件编号)` 唯一，批末重裁只处理「待批末」，重复落账被吞。
- **并发**：装载、批末重裁、跑对齐全部 `BEGIN IMMEDIATE`；裁决与流水同一事务成败。
- **只读裁决**：`GET /api/时钟漂移/裁决?业务键=…` 返回业务键、事件时、处理时、命运、valid。
- **窗口**：UTC 左闭右开 `[开始, 结束)`；严格/缓冲缺有效窗口时装载一律驳回。

冒烟：`时钟漂移` 页切「事件时严格」→ 左轨灌「左轨时钟样例」→ 看旁路账册；切「处理时缓冲」→ 灌完后点「批末重裁」看包状态流转。
